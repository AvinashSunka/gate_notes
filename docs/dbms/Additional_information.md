# Database vs DBMS

[Video link](https://youtu.be/3EJlovevfcA)

- Databases are of 2 types :
	1. **Structured databases** ( also called Relational Databases )
		- Data is in the format of tables
	2. **Unstructured databases** ( Not required for gate )

- DBMS : 
	- The technologies used for managing the databases are called DBMS
	- Ex :
		1. SQL server
		2. Oracle server
		3. My SQL
